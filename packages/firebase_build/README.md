# tekartik_firebase_build.dart

Firebase build helper

## Setup

```yaml
dependencies:
  tekartik_firebase_build:
    git:
      url: https://github.com/tekartik/app_build.dart
      path: packages/firebase_build
    version: '>=0.1.0'
```

## Usage

Building and deploying a flutter web app to firebase hosting is
`app_build.dart` (`FlutterFirebaseWebAppBuilder`) and `firebase_deploy.dart`;
driving the `firebase` cli on a firebase folder is `firebase_project.dart`
(`FirebaseProjectBuilder`, from `tekartik_firebase_tools_common`).

The firestore rules and indexes of an app live in `deploy/firebase/firestore`
(`FirebaseProjectBuilderExt.defaultFirestoreDir`), next to the hosting folder:

```dart
import 'package:tekartik_firebase_build/firebase_project.dart';

await FirebaseProjectBuilderExt.firestoreFolder(
  projectId: 'my-project-dev',
).deployFirestore();
```

The firebase options of an app (`lib/firebase_options.dart`, or one file per
flavor: `FirebaseFlutterProjectBuilder.flavor(projectId: 'my-project-dev',
flavor: 'dev', platforms: ['web'])` for `lib/firebase_options_dev.dart`) are
generated by the `flutterfire` cli:

```dart
import 'package:tekartik_firebase_build/flutterfire_configure.dart';

await FirebaseFlutterProjectBuilder(
  options: FirebaseFlutterProjectOptions(
    projectId: 'my-project-dev',
    platforms: ['web'],
    firebaseOptionsFile: 'lib/firebase_options_dev.dart',
  ),
).configure();
```
